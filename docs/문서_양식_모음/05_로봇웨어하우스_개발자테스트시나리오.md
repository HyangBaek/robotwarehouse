# 개발자 테스트 시나리오

| 항목 | 내용 |
|---|---|
| 근거 문서 | 구현 시나리오 v0.1 (SC·EX), 요구사항 명세서 v0.1 (FR·NFR) |
| 팀 | 로봇웨어하우스 (방유진 · 백향 · 하재윤) |
| 문서 버전 | v0.1 (2026-09-30 초안) |

**사용법**
- 테스트 케이스(TC) 하나는 "입력 하나에 기대 결과 하나"입니다. 담당자는 자기 구성 요소의 TC를 코드로 자동화하고, 자동화가 어려운 VR·실기기 TC는 체크리스트로 수행합니다.
- 우선순위는 요구사항 등급을 따릅니다. P0 TC는 10/2 E2E 전까지 모두 통과해야 합니다.
- 함수 이름, 파일 경로, API 이름은 설계 예시입니다. 실제 코드에 맞춰 고칩니다.

## 0. 테스트 기준

### 0.1 테스트 수준

| 수준 | 약어 | 대상 | 도구 | 실행 시점 |
|---|---|---|---|---|
| 단위 | UT | 검증 도구, 지도 생성, 경로 엔진, 집계 함수 | pytest | 커밋 전 |
| 통합 | IT | FastAPI 엔드포인트, WebSocket, Agent 그래프(LLM 모의 응답) | pytest + httpx, FastAPI TestClient | 병합 전 |
| LLM 평가 | LT | 실제 LLM으로 지시 해석·질문·설명 품질 확인 | pytest (마커 `llm`) | 하루 1회 (API 비용 고려) |
| Unity | UN | 좌표 변환, 블록 생성, 재생 보간 | Unity Test Framework (EditMode/PlayMode) | 빌드 전 |
| 실기기 | DV | Quest 2에서 VR 동작, 음성, 네트워크 | 수동 체크리스트 | 매일 저녁 통합 빌드 |
| 종단 | E2E | 음성 입력 → VR 재생 전체 흐름 | 수동 + 서버 로그 확인 | 10/2부터 매일 |
| 성능 | PF | FPS, 응답 시간, 재계획 시간 | Quest 성능 오버레이, 서버 타이머 로그 | 10/2, 10/4 |

### 0.2 TC ID 규칙

`TC-[구성요소]-[번호]` — MAP(지도 생성·검증), AGT(Agent), ENG(경로 엔진), API(서버 인터페이스), VR(Unity·실기기), ANL(분석·개선), E2E, EX(예외), PF(성능)

### 0.3 실행 방법

```bash
# 서버 전체 단위·통합 테스트 (LLM 호출 없음)
cd server
pytest -m "not llm" -q

# 구성 요소별
pytest tests/test_map_validator.py -q
pytest tests/test_engine.py -q

# 실제 LLM 평가 (하루 1회, .env에 API 키 필요)
pytest -m llm -q --maxfail=20

# 충돌 검사만 빠르게: 모든 픽스처 시나리오 × 두 전략
pytest tests/test_engine.py -k collision -q
```

Unity: Window → General → Test Runner → EditMode / PlayMode → Run All

### 0.4 통과 판정

- 자동 TC: pytest 결과 `passed`
- 수동 TC: 기대 결과를 모두 만족하면 통과, 하나라도 다르면 실패로 기록하고 버그 번호를 붙임 (7장 양식)
- LLM 평가(LT): 케이스 단위 통과율로 판정. 목표 통과율은 10/1 첫 측정 뒤 팀이 정함

## 1. 테스트 픽스처

> `server/tests/fixtures/` 아래 파일로 만들어 모든 TC가 같은 데이터를 씁니다.

| 파일 | 내용 | 용도 |
|---|---|---|
| `maps/w1_small.json` | W1 기대 지도 (랙 4줄, 통로 3m, 입하 1, 출하 1) | 정상 지도 |
| `maps/w2_demo.json` | W2 기대 지도 (랙 8줄, 입하 2, 출하 1, 충전 오른쪽) | 시연 기본 |

| `maps/bad_unreachable.json` | 통로로 닿지 않는 랙이 있는 지도 | 검증 실패 |
| `maps/bad_no_dock_in.json` | 입하 도크 없는 지도 | 검증 실패 |
| `maps/bad_schema.json` | `width` 누락, 잘못된 `type` 값 포함 | 형식 오류 |
| `maps/bad_unreachable_no_dock.json` | 도달 불가 + 입하 도크 없음이 함께 있는 지도 | 복수 오류 |
| `maps/bad_size.json` | `cells` 좌표가 `width`·`height` 범위 밖 | 형식 오류 |
| `maps/tiny_corridor.json` | 폭 1칸 통로 양 끝에 로봇 2대 | 맞교환 충돌 유도 |

| `llm/*.json` | 지시 해석·질문·분석 노드의 모의 LLM 응답 | IT에서 LLM 대체 |
| `audio/w1.wav`, `w2.wav`, `silence.wav`, `noise.wav` | 녹음 파일 | STT 테스트 |
| `sentences.csv` | W1~W3를 표현만 바꾼 문장 `[N]`개 + 기대 요구사항 | 지도 생성 성공률 (NFR-05) |

W2-a,"랙 8줄, 통로 폭 3m, 입하 도크 2개, 출하 도크 1개, 충전 구역은 오른쪽 벽 쪽에",8,3,2,1
```

### 2.4 경로 계산 엔진 — SC-04, SC-07, SC-08 (담당: 하재윤)

**불변 조건 (모든 시뮬레이션 결과에 공통으로 검사하는 함수 `assert_invariants(log, map)`)**

1. 같은 스텝에 두 로봇이 같은 칸에 있지 않다 (칸 충돌)
2. 두 로봇이 한 스텝 사이에 서로 자리를 바꾸지 않는다 (맞교환 충돌)
3. 로봇은 한 스텝에 상하좌우 한 칸 이동하거나 제자리 대기만 한다
4. 로봇은 벽·랙 칸에 들어가지 않는다 (랙 작업은 인접 통로 칸에서 수행)
5. 일방통행 구간에서 반대 방향으로 이동하지 않는다
6. 모든 주문이 정확히 한 번 완료된다

import pytest
from conftest import load
from tools.map_validator import validate_map

def codes(result):
    return {e["code"] for e in result["errors"]}

def test_valid_map_passes():
    r = validate_map(load("maps/w1_small.json"))
    assert r["valid"] and r["errors"] == []

def test_unreachable_cells_reported():
    m = load("maps/bad_unreachable.json")
    r = validate_map(m)
    assert not r["valid"]
    err = next(e for e in r["errors"] if e["code"] == "UNREACHABLE")
    assert sorted(map(tuple, err["cells"])) == sorted(map(tuple, m["_expected_unreachable"]))

def test_multiple_errors_all_reported():
    r = validate_map(load("maps/bad_unreachable_no_dock.json"))
    assert {"UNREACHABLE", "NO_DOCK_IN"} <= codes(r)
```

### 3.3 경로 엔진 불변 조건 (TC-ENG-07~09, 11)

```python
import pytest
from engine import simulate

BLOCKED = {"wall", "rack"}

def assert_invariants(log, grid):
    cell_type = {(c["x"], c["y"]): c["type"] for c in grid["cells"]}
    frames = log["frames"]
    for f in frames:
        pos = [(r["x"], r["y"]) for r in f["robots"]]
        assert len(pos) == len(set(pos)), f"칸 충돌 t={f['t']}"
        for p in pos:
            assert cell_type.get(p, "aisle") not in BLOCKED, f"금지 칸 진입 t={f['t']} {p}"
    for a, b in zip(frames, frames[1:]):
        prev = {r["id"]: (r["x"], r["y"]) for r in a["robots"]}
        curr = {r["id"]: (r["x"], r["y"]) for r in b["robots"]}
        for rid, (x, y) in curr.items():
            px, py = prev[rid]
            assert abs(x - px) + abs(y - py) <= 1, f"순간이동 t={b['t']} robot={rid}"
        for r1 in curr:
            for r2 in curr:
                if r1 < r2 and prev[r1] == curr[r2] and prev[r2] == curr[r1]:
                    raise AssertionError(f"맞교환 충돌 t={b['t']} {r1}<->{r2}")
    done = [o["order_id"] for o in log["orders"] if o["done_t"] is not None]
    assert len(done) == len(set(done)) == len(log["orders"]), "주문 누락 또는 중복 완료"

@pytest.mark.parametrize("strategy", ["optimized", "baseline"])
def test_no_collision(map_w2, scenario, strategy):
    log = simulate(map_w2, scenario, strategy=strategy, seed=42)
    assert_invariants(log, map_w2)

def test_head_on_corridor():
    from conftest import load
    m = load("maps/tiny_corridor.json")
    log = simulate(m, load("scenarios/tiny_corridor.json"), strategy="optimized", seed=0)
    assert_invariants(log, m)
```

### 3.4 모의 LLM으로 Agent 흐름 (TC-AGT-02~04)

```python
from agent.graph import build_graph

class FakeLLM:
    def __init__(self, replies):
        self.replies = list(replies)
    def invoke(self, *_args, **_kw):
        return self.replies.pop(0)

def test_question_then_regenerate(load_llm):
    llm = FakeLLM(load_llm("unreachable_then_fixed.json"))
    g = build_graph(llm=llm)
    s = g.invoke({"text": "랙 10줄을 통로 없이 붙여줘"})
    assert s["event"] == "question"
    s = g.invoke({**s, "answer": "통로 3m로 해줘"})
    assert s["event"] == "map_ready" and s["validation"]["valid"]

def test_question_limit(load_llm):
    llm = FakeLLM(load_llm("always_unreachable.json"))
    g = build_graph(llm=llm)
    s = g.invoke({"text": "랙 10줄을 통로 없이"})
    for _ in range(3):
        s = g.invoke({**s, "answer": "그대로 해줘"})
    assert s["event"] == "abort"
```

import csv, pytest
from conftest import FIX
from agent.parse import extract_requirements

ROWS = list(csv.DictReader(open(FIX / "sentences.csv", encoding="utf-8")))
KEYS = ["racks", "aisle_width", "dock_in", "dock_out"]
