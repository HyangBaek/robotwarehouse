# 통합 테스트 케이스

| 항목 | 내용 |
|---|---|
| 근거 문서 | 개발자 테스트 시나리오 v0.1, 구현 시나리오 v0.1, 요구사항 명세서 v0.1, 시스템 아키텍처 |
| 팀 | 로봇웨어하우스 (방유진 · 백향 · 하재윤) |
| 문서 버전 | v0.1 (2026-09-30 초안) |
| 별도 문서 | E2E 필수 시연 케이스 → `로봇웨어하우스_E2E필수시연케이스.md` |

**이 문서의 범위**
- 단위 테스트를 통과한 구성 요소를 **서로 붙였을 때** 데이터와 제어가 경계를 제대로 넘는지 확인합니다.
- 개발자 테스트 시나리오의 IT 항목(TC-AGT, TC-API)을 경계별 절차·확인 위치까지 풀어 쓴 문서입니다. 두 문서의 ID는 5장 추적표로 연결됩니다.
- API 경로·메시지 이름은 설계 예시입니다. `docs/api.md`와 다르면 그 문서를 따릅니다.

---

## 0. 통합 기준

### 0.1 통합 경계

```
[VR 클라이언트] ─B1(REST/WS)─ [게이트웨이] ─B2─ [Agent 그래프] ─B3─ [도구] ─B4─ [경로 엔진]
                                  │                   │                         │
                                  B6(STT·TTS)        B5(LLM)                   B7(SQLite)
```

| 경계 | 연결 | 주로 깨지는 지점 |
|---|---|---|
| B1 | VR ↔ 게이트웨이 | 필드 이름·타입 불일치, 메시지 순서, 좌표계, 재연결 |
| B2 | 게이트웨이 ↔ Agent | 세션 상태 전달, 비동기 이벤트를 WS로 내보내는 시점 |
| B3 | Agent ↔ 도구 | 도구 입력 형식, 오류 코드 전달 |
| B4 | 도구 ↔ 경로 엔진 | `map_version`·시나리오 전달, 로그 형식(DR-03) |
| B5 | Agent ↔ LLM | 깨진 JSON, 응답 지연, 스키마 이탈 |
| B6 | 게이트웨이 ↔ STT·TTS | 오디오 포맷, 빈 인식 결과, 시간 초과 |
| B7 | 도구·엔진 ↔ SQLite | 저장·조회 일관성, 버전 추적 |

### 0.2 통합 환경

| 환경 | 구성 | 외부 API | 용도 |
|---|---|---|---|
| **ENV-1** 서버 단독 | FastAPI TestClient + 모의 LLM·STT·TTS + 실제 엔진·SQLite(임시 파일) | 모의 | B2~B4, B7 자동 테스트 |
| **ENV-2** 서버 + Unity Editor | 노트북에서 서버 실행, Unity Editor Play 모드로 접속 | 모의 또는 실제 | B1 계약·좌표·재생 확인 |
| **ENV-3** 실제 API | ENV-1과 같고 LLM·STT·TTS만 실제 호출 | 실제 | B5, B6 |
| **ENV-4** 실기기 | 서버 노트북 + Quest 2 APK, 같은 Wi-Fi | 실제 | 최종 통합, 네트워크·성능 |

> Unity 쪽에는 **모의 서버 모드**(서버 없이 픽스처 JSON을 순서대로 흘려보내는 설정)를 두면, 서버가 준비되지 않은 날에도 B1 수신 측을 먼저 확인할 수 있습니다.

### 0.3 진입·종료 기준

| 구분 | 기준 |
|---|---|
| 진입 | 해당 구성 요소의 P0 단위 테스트 통과, `docs/api.md`·`docs/schema.md` 버전이 양쪽 코드와 같음 |
| 종료 (10/2) | P0 통합 케이스 전부 통과, 치명·높음 버그 0건 |
| 종료 (10/4) | P1 통합 케이스 통과 또는 "제외 결정" 기록, 전체 회귀 1회 통과 |

### 0.4 통합 순서 (아래에서 위로)

1. **10/1 오전** B3·B4·B7 (ENV-1): Agent 없이 도구 → 엔진 → DB
2. **10/1 오후** B2·B5 (ENV-1, 모의 LLM): 게이트웨이 → Agent 그래프 전체
3. **10/1 저녁** B1 (ENV-2): Unity Editor로 지도 수신·표시
4. **10/2 오전** B5·B6 (ENV-3): 실제 LLM·STT
5. **10/2 오후** ENV-4 실기기 → 저녁 E2E 필수 시연 케이스

### 0.5 실행 방법

```bash
# ENV-1: 서버 통합 테스트 (외부 API 모의)
cd server
pytest tests/integration -m "not live" -q

# ENV-3: 실제 외부 API 통합 (하루 1회)
pytest tests/integration -m live -q

# ENV-2 / ENV-4: 서버 실행 후 Unity 또는 Quest 2에서 수동 절차 수행
uvicorn api.main:app --host 0.0.0.0 --port 8000 --log-level info
```

### 0.6 케이스 표기

- **등급:** P0(10/2 전 필수) · P1(10/4 전) · P2(여유 시)
- **확인 위치:** `WS` WebSocket 수신 메시지 · `LOG` 서버 로그 · `DB` SQLite 조회 · `VR` 화면 · `RES` REST 응답

## 7. 자동화 예시 (ENV-1)

```python
# server/tests/integration/test_flow_map_to_sim.py
import pytest
from fastapi.testclient import TestClient
from api.main import create_app
from tests.fakes import FakeLLM, FakeSTT, load_llm

@pytest.fixture
def client(tmp_path):
    app = create_app(
        db_path=tmp_path / "test.db",
        llm=FakeLLM(load_llm("w2_requirements.json")),
        stt=FakeSTT({"w2.wav": "랙 8줄, 통로 폭 3m, 입하 도크 2개, 출하 도크 1개"}),
    )
    return TestClient(app)

def recv_until(ws, type_, limit=20):
    seen = []
    for _ in range(limit):
        m = ws.receive_json()
        seen.append(m["type"])
        if m["type"] == type_:
            return m, seen
    raise AssertionError(f"{type_} 미수신, 받은 순서: {seen}")

def test_itc02_05_17_map_confirm_simulate(client):
    with client.websocket_connect("/ws") as ws:
        sid = ws.receive_json()["session_id"]                       # ITC-01

        r = client.post("/map/text", json={"session_id": sid, "text": "랙 8줄 ..."})
        assert r.status_code == 200
        m, _ = recv_until(ws, "map_ready")                          # ITC-02
        v = m["map_version"]

        r = client.post("/scenario", json={"session_id": sid, "map_version": v,
                                           "robots": 4, "inbound": 25, "outbound": 25})
        assert r.status_code >= 400                                  # ITC-05 차단

        client.post("/map/confirm", json={"session_id": sid, "map_version": v})
        r = client.post("/scenario", json={"session_id": sid, "map_version": v,
                                           "robots": 4, "inbound": 25, "outbound": 25})
        sim_id = r.json()["sim_id"]
        s, _ = recv_until(ws, "sim_ready")                           # ITC-17
        assert s["sim_id"] == sim_id

        total = s["total_steps"]                                     # ITC-07
        frames, t0 = [], 0
        while t0 <= total:
            frames += client.get(f"/sim/{sim_id}/frames",
                                 params={"from": t0, "to": t0 + 199}).json()
            t0 += 200
        assert [f["t"] for f in frames] == list(range(total + 1))

def test_itc03_transcript_before_map_ready(client):
    with client.websocket_connect("/ws") as ws:
        sid = ws.receive_json()["session_id"]
        with open("tests/fixtures/audio/w2.wav", "rb") as f:
            client.post("/map/voice", data={"session_id": sid},
                        files={"audio": ("w2.wav", f, "audio/wav")})
        _, seen = recv_until(ws, "map_ready")
        assert seen.index("transcript") < seen.index("map_ready")
```

> `create_app`이 LLM·STT·DB를 인자로 받도록(의존성 주입) 만들어 두면, 같은 코드로 ENV-1(모의)과 ENV-3(실제)을 오갈 수 있습니다.
